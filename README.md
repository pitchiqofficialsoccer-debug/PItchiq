# PitchIQ homepage

A dark, responsive Next.js landing-page starter for PitchIQ, initially focused on midfielder development.

## Run locally

1. Install Node.js 20.9 or newer.
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Current scope

- Responsive landing page
- PitchIQ dark sports-tech visual direction
- Midfielder-first messaging
- Product pillars and development journey
- Early-access call to action
